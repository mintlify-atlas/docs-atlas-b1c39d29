## Why TailAdmin?

TailAdmin is a free, production-ready admin dashboard template that gives you a complete foundation for building back-end interfaces, admin panels, and data-driven dashboards — without starting from scratch.

Built on **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**, it delivers a modern developer experience with a clean, professional UI out of the box.

## Quick start

```bash
git clone https://github.com/TailAdmin/free-nextjs-admin-dashboard.git
cd free-nextjs-admin-dashboard
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the dashboard.
