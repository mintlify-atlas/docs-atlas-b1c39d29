## Free vs Pro

| Feature | Free | Pro |
|---|---|---|
| Unique dashboards | 1 | 7 |
| Dashboard components | 30+ | 500+ |
| UI elements | 50+ | 500+ |
| Figma design file | Basic | Complete |
| Support | Community | Email |

## Free version

The free version includes everything you need to build a single admin dashboard:

- **1 unique dashboard** — Ecommerce dashboard with metrics, charts, orders table, and map
- **30+ dashboard components** — Charts, tables, stat cards, and data visualizations
- **50+ UI elements** — Buttons, alerts, badges, modals, dropdowns, avatars, and more
- **Basic Figma design file** — Community edition design reference
- **Community support** — GitHub issues and community discussions
- **Full source code** — MIT licensed, no restrictions

## Pro version

The Pro version significantly expands the template with seven purpose-built dashboards, a complete component library, and direct support.

## Pro dashboards

The seven Pro dashboards are each tailored to a specific domain:

| Dashboard | Focus area |
|---|---|
| **Analytics** | Traffic, conversions, and engagement metrics |
| **Ecommerce** | Orders, revenue, and product performance |
| **Marketing** | Campaigns, funnels, and audience data |
| **CRM** | Contacts, deals, and pipeline management |
| **SaaS** | Subscriptions, MRR, and churn tracking |
| **Stocks** | Portfolio, watchlists, and market data |
| **Logistics** | Shipments, routes, and delivery tracking |
