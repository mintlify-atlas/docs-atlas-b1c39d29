## Overview

TailAdmin uses **Tailwind CSS v4**, which replaces `tailwind.config.js` with a CSS-first configuration approach. All colors are defined as CSS custom properties inside the `@theme` block in `src/app/globals.css`. Tailwind reads these variables and automatically generates utility classes like `bg-brand-500`, `text-gray-900`, and `border-error-200`.

<Note>
  There is no `tailwind.config.js` in this project. Every color token lives in `src/app/globals.css` under the `@theme` directive.
</Note>

## Brand color scale

The brand palette is TailAdmin's primary color system. It maps to a perceptual scale from 25 (near-white) to 950 (near-black), anchored at `#465fff` for the `500` step.

```css src/app/globals.css
@theme {
  --color-brand-25:  #f2f7ff;
  --color-brand-50:  #ecf3ff;
  --color-brand-100: #dde9ff;
  --color-brand-200: #c2d6ff;
  --color-brand-300: #9cb9ff;
  --color-brand-400: #7592ff;
  --color-brand-500: #465fff;
  --color-brand-600: #3641f5;
  --color-brand-700: #2a31d8;
  --color-brand-800: #252dae;
  --color-brand-900: #262e89;
  --color-brand-950: #161950;
}
```

These map directly to Tailwind utilities:

| CSS variable | Tailwind class examples |
|---|---|
| `--color-brand-500` | `bg-brand-500`, `text-brand-500`, `border-brand-500` |
| `--color-brand-50` | `bg-brand-50`, `hover:bg-brand-50` |
| `--color-brand-600` | `hover:bg-brand-600`, `focus:ring-brand-600` |

## Changing the primary brand color

To replace the blue brand palette with your own color, update the `--color-brand-*` variables in `src/app/globals.css`. Every component that uses `bg-brand-500`, `text-brand-600`, or similar will update automatically.

<Steps>
  <Step title="Open globals.css">
    Open `src/app/globals.css` and locate the brand color block inside `@theme`.
  </Step>
  <Step title="Replace the brand values">
    Swap every `--color-brand-*` value with your own color scale. Keep the same number of stops (25 through 950) to maintain consistent contrast across states.

    ```css src/app/globals.css
    @theme {
      --color-brand-25:  #fdf4ff;
      --color-brand-50:  #fae8ff;
      --color-brand-100: #f3d0fe;
      --color-brand-200: #e9a8fc;
      --color-brand-300: #d671f7;
      --color-brand-400: #c042ef;
      --color-brand-500: #a516d4; /* your primary */
      --color-brand-600: #8b10b0;
      --color-brand-700: #730d92;
      --color-brand-800: #5e0c75;
      --color-brand-900: #4a0a5c;
      --color-brand-950: #2d0638;
    }
    ```
  </Step>
  <Step title="Verify the result">
    Run `npm run dev` and check that buttons, active sidebar items, links, and focus rings all reflect the new color.
  </Step>
</Steps>

<Tip>
  Color names follow a numeric scale where **500 is the main interactive color**, lighter steps (50–300) are used for backgrounds and hover states, and darker steps (600–950) are used for pressed states and text.
</Tip>

## Utility class reference

Every CSS variable registered under `--color-*` in the `@theme` block becomes available as a Tailwind utility class using the segment after `--color-` as the class name.

```tsx
{/* Backgrounds */}
<div className="bg-brand-50 dark:bg-brand-500/[0.12]" />
<div className="bg-gray-100 dark:bg-gray-800" />
<div className="bg-success-50" />

{/* Text */}
<span className="text-brand-500 dark:text-brand-400" />
<span className="text-gray-700 dark:text-gray-300" />
<span className="text-error-600" />

{/* Borders */}
<input className="border-gray-300 focus:border-brand-500" />
<div className="border-warning-200" />
```
