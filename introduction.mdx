## What is TailAdmin?

TailAdmin is a free, production-ready admin dashboard template that gives developers a head start when building back-end interfaces, admin panels, and data-driven dashboards. It combines the power of **Next.js 16** with the utility-first styling of **Tailwind CSS v4** to deliver a modern, responsive, and fully customizable starting point.

Built with **React 19** and **TypeScript**, TailAdmin is designed to integrate cleanly into any web project — whether you're building a simple internal tool or a complex SaaS application.

## Technology stack

| Technology | Version | Purpose |
|---|---|---|
| Next.js | 16.x | React framework with App Router and SSR |
| React | 19.x | UI component rendering |
| TypeScript | 5.x | Static typing |
| Tailwind CSS | v4 | Utility-first styling |
| ApexCharts | 4.x | Line and bar chart visualization |
| FullCalendar | 6.x | Interactive calendar component |
| flatpickr | 4.x | Date and time picker |
| jVectorMap | — | Interactive world map |
| react-dropzone | 14.x | Drag-and-drop file upload |
| Swiper | 11.x | Touch-friendly carousels |
