## Overview

TailAdmin provides two avatar components:

- **`Avatar`** — displays a circular profile image with an optional status dot.
- **`AvatarText`** — displays initials generated from a name, with a deterministic pastel background color.

## Import

```tsx
import Avatar from "@/components/ui/avatar/Avatar";
import AvatarText from "@/components/ui/avatar/AvatarText";
```

## `Avatar` component

### Props

<ParamField path="src" type="string" required>
  The URL of the avatar image. Passed to Next.js `Image` as the `src` prop.
</ParamField>

<ParamField path="alt" type="string" default="User Avatar">
  Alternative text for the image, used by screen readers.
</ParamField>

<ParamField path="size" type="xsmall | small | medium | large | xlarge | xxlarge" default="medium">
  Controls the diameter of the avatar circle.

  | Size | Diameter |
  |------|----------|
  | `xsmall` | 24 px (`h-6 w-6`) |
  | `small` | 32 px (`h-8 w-8`) |
  | `medium` | 40 px (`h-10 w-10`) |
  | `large` | 48 px (`h-12 w-12`) |
  | `xlarge` | 56 px (`h-14 w-14`) |
  | `xxlarge` | 64 px (`h-16 w-16`) |
</ParamField>

<ParamField path="status" type="online | offline | busy | none" default="none">
  Renders a small colored dot in the bottom-right corner of the avatar.

  | Status | Color |
  |--------|-------|
  | `online` | `bg-success-500` (green) |
  | `offline` | `bg-error-400` (red) |
  | `busy` | `bg-warning-500` (orange) |
  | `none` | No indicator rendered |
</ParamField>

### Usage

#### Basic avatar

```tsx
<Avatar src="/images/user/avatar-01.png" />
```

#### Size variants

```tsx
<Avatar src="/images/user/avatar-01.png" size="xsmall" />
<Avatar src="/images/user/avatar-01.png" size="small" />
<Avatar src="/images/user/avatar-01.png" size="medium" />
<Avatar src="/images/user/avatar-01.png" size="large" />
<Avatar src="/images/user/avatar-01.png" size="xlarge" />
<Avatar src="/images/user/avatar-01.png" size="xxlarge" />
```

#### Status indicators

```tsx
<Avatar src="/images/user/avatar-01.png" size="medium" status="online" />
<Avatar src="/images/user/avatar-01.png" size="medium" status="offline" />
<Avatar src="/images/user/avatar-01.png" size="medium" status="busy" />
```

#### Avatar with custom alt text

```tsx
<Avatar
  src="/images/user/avatar-02.png"
  alt="Jane Doe profile picture"
  size="large"
  status="online"
/>
```

## `AvatarText` component

`AvatarText` generates a circular avatar from a person's name. It extracts up to two initials and picks a pastel background color derived from the name string — so the same name always renders the same color.

### Props

<ParamField path="name" type="string" required>
  The full name used to generate initials and the background color. Spaces separate words; the first letter of each word becomes an initial (up to two).
</ParamField>

<ParamField path="className" type="string">
  Additional Tailwind classes merged onto the wrapper `<div>`. The component is `h-10 w-10` by default.
</ParamField>

### Usage

```tsx
<AvatarText name="Jane Doe" />
<AvatarText name="John Smith" />
<AvatarText name="Alice" />
```

#### Custom size

Override the default dimensions with `className`:

```tsx
<AvatarText name="Jane Doe" className="h-12 w-12 text-base" />
```

### Color palette

The background is chosen deterministically from eight pastel color pairs:

| Color | Background | Text |
|-------|-----------|------|
| Brand | `bg-brand-100` | `text-brand-600` |
| Pink | `bg-pink-100` | `text-pink-600` |
| Cyan | `bg-cyan-100` | `text-cyan-600` |
| Orange | `bg-orange-100` | `text-orange-600` |
| Green | `bg-green-100` | `text-green-600` |
| Purple | `bg-purple-100` | `text-purple-600` |
| Yellow | `bg-yellow-100` | `text-yellow-600` |
| Error | `bg-error-100` | `text-error-600` |

The index into this array is the sum of the character codes of all characters in `name`, modulo 8.

## Avatar group

Stack multiple avatars by applying a negative margin:

```tsx
<div className="flex -space-x-2">
  <Avatar src="/images/user/avatar-01.png" size="medium" />
  <Avatar src="/images/user/avatar-02.png" size="medium" />
  <Avatar src="/images/user/avatar-03.png" size="medium" />
  <AvatarText name="Jane Doe" />
</div>
```
