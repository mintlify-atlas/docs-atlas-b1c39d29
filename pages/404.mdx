## Overview

When a user navigates to a route that does not exist, Next.js App Router automatically renders `src/app/not-found.tsx`. TailAdmin ships a custom version of this file that displays a large **ERROR** heading, an SVG 404 illustration (with separate light and dark variants), a friendly message, and a **Back to Home Page** button.

## Next.js App Router Convention

Next.js App Router treats `not-found.tsx` as a special file. When you call the `notFound()` helper from `next/navigation` anywhere in your application, or when a dynamic segment cannot be resolved, the router automatically renders the nearest `not-found.tsx` up the file-system tree.

<Note>
  `not-found.tsx` at the root of `src/app/` is the **global** 404 handler. You can also create scoped `not-found.tsx` files inside nested route segments (e.g. `src/app/(admin)/products/not-found.tsx`) to show segment-specific error messages.
</Note>

### Triggering `notFound()` manually

```tsx
import { notFound } from "next/navigation";

export default async function ProductPage({ params }: { params: { id: string } }) {
  const product = await fetchProduct(params.id);

  if (!product) {
    notFound(); // renders not-found.tsx
  }

  return <div>{product.name}</div>;
}
```

## Customizing the 404 Page

### Change the message

Edit the `<p>` tag text directly in `not-found.tsx`:

```tsx
<p className="mt-10 mb-6 text-base text-gray-700 dark:text-gray-400 sm:text-lg">
  This page has moved or no longer exists. Try searching instead.
</p>
```

### Change the illustration

Replace the SVG files at:

```
public/images/error/404.svg       ← light mode
public/images/error/404-dark.svg  ← dark mode
```

Keep the same filenames so the existing `<Image>` tags continue to work, or update the `src` props if you use different filenames.

### Add a search input

Convert `not-found.tsx` to a client component (`"use client"`) and add a search field above the back-to-home button:

```tsx
"use client";
import { useState } from "react";
import { useRouter } from "next/navigation";

// Inside the component:
const [query, setQuery] = useState("");
const router = useRouter();

<input
  value={query}
  onChange={(e) => setQuery(e.target.value)}
  onKeyDown={(e) => e.key === "Enter" && router.push(`/search?q=${query}`)}
  placeholder="Search..."
  className="mt-4 rounded-lg border border-gray-300 px-4 py-2 text-sm"
/>
```

<Warning>
  Avoid adding `export const metadata` to a `"use client"` component — metadata exports only work in Server Components. Keep metadata in a separate parent layout or remove it when converting to a client component.
</Warning>
