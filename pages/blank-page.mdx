## Overview

The blank page lives at `/blank` and is rendered by `src/app/(admin)/(others-pages)/blank/page.tsx`. It gives you a ready-made shell that already includes:

- A `PageBreadcrumb` for consistent navigation context
- A `rounded-2xl` card panel with correct border and background tokens for both light and dark mode
- Responsive horizontal padding (`px-5 xl:px-10`) and vertical padding (`py-7 xl:py-12`)
- A centred placeholder title and body text you can replace immediately

Use this page as the starting point whenever you need to add a new section to the admin dashboard.

## Creating a New Page From the Blank Template

<Steps>
  <Step title="Duplicate the directory">
    Copy `src/app/(admin)/(others-pages)/blank/` to a new folder with the route name you want, e.g. `src/app/(admin)/(others-pages)/reports/`.
  </Step>
  <Step title="Update the metadata">
    Edit the `metadata` export at the top of `page.tsx` to reflect the new page title and description.

    ```tsx
    export const metadata: Metadata = {
      title: "Reports | TailAdmin",
      description: "Monthly and annual reports overview.",
    };
    ```
  </Step>
  <Step title="Update the breadcrumb">
    Change the `pageTitle` prop on `PageBreadcrumb` to match your new page name:

    ```tsx
    <PageBreadcrumb pageTitle="Reports" />
    ```
  </Step>
  <Step title="Replace the placeholder content">
    Remove the `max-w-[630px]` centred placeholder and add your own components inside the card panel. Use the 12-column grid from the ecommerce dashboard as a reference for multi-column layouts.
  </Step>
  <Step title="Add to navigation">
    Register the new route in `docs.json` (for documentation) or in the sidebar data file in `src/components/layout/AppSidebar.tsx` so users can navigate to it.
  </Step>
</Steps>

## Card Panel Tokens

The blank page uses these Tailwind classes for the content card. Keep them when building new pages to stay visually consistent with the rest of the dashboard:

| Class | Purpose |
|---|---|
| `rounded-2xl` | Consistent corner radius across all cards |
| `border border-gray-200` | Light-mode border |
| `dark:border-gray-800` | Dark-mode border |
| `bg-white` | Light-mode background |
| `dark:bg-white/[0.03]` | Dark-mode semi-transparent background |
| `px-5 xl:px-10` | Responsive horizontal padding |
| `py-7 xl:py-12` | Responsive vertical padding |

<Tip>
  All other pages in TailAdmin follow the same card token conventions. Copy the outer `<div>` wrapper from the blank page rather than writing it from memory.
</Tip>
